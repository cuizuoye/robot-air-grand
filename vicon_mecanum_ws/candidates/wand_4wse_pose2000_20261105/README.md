# 4WSE定位时限2000毫秒候选

父版本为中文提示版 `wand_4wse_zh_errors_20261105`；两个旧版本均不修改。

## 明确改变

定位有效期为2000毫秒：Sign刚体及五点同帧包、原始车体位姿、组合证据、
缓存引用、监督器/末级门、跟随算法输入和准备提示使用一致的定位时限。
原始源时间戳和首次接收时间保持不变；重复、乱序或迟到帧不能重新计时。
在恰好2秒时仍在时限内，超过2秒才因定位超时停车；实际检测还受调度周期影响。

此参数由本项目设置，不是Vicon规定。它容忍的是数据空窗，不会消除空窗原因，
也不会提高真实定位或运动同步性。0.70m/s运行2秒对应1.4米的运动距离，
因此不能把该版本称为已验证安全的演示版本。

## 保持不变

- 0.70m/s、2.00m/s²、2.00rad/s、12.00rad/s²；1:1平移和相对旋转。
- 最长600秒、单击启停、无固定电子围栏、域0接收器隔离、中文故障说明。
- 100ms控制及验签指令有效期、500ms反馈、STM32的600ms有效命令保护。
- 来源身份、同帧、几何、签名、跳变/倾斜/抬起、显式停止和停车证据检查。
- 固件、Tenda和其他项目配置；不自动清故障或恢复已结束会话。

今天5次失败中4次最初是定位超时，另1次是验签指令更新超时；
后者不能通过修改定位时限解决。完整诊断见 `evidence/RECENT_FAILURES.json`。

## 验证边界

仅离线/本机回环验证；不初始化真实Vicon接收器，不连接真实小车，不刷写或运动。
600秒实车、停车包络及电气/温升没有因这些软件回归而获得新的验收结论。
