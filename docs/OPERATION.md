# 完成一轮空地协同

以下为已部署实验室机器的操作流程。新机器先完成[部署说明](DEPLOYMENT.md)，不要把配置快照当作现场完成配置。

## 打开操作台

```bash
bash /home/czy/vicon_receiver_ws/drone_sim/tools/gamepad_rc/run_drone_console.sh --live
```

这是现场原入口，打开窗口只显示界面。正式任务入口为同目录的 `vicon_fixed_point_entry.py`；GUI 通过 `joint_console_run.py` 调用它，没有第二套飞行发送器。

## 一轮流程

1. **选择计划**：短线 1 m 往返、矩形 3×2 m 或直径 1.5 m 圆周。圆周联合实飞属于待验证功能。
2. **准备连接**：车机静止，Vicon 两刚体有效，Pocket 开启且保持解锁关闭，重复任务/QGC 关闭。点击一次准备，程序核对两块专用网卡及保存的热点连接，恢复定位和遥测；问题显示在阶段与故障区。
3. **小车自动就位**：确认接近和转向空间后启动。小车绕开地面无人机，停到左侧约 0.51 m 并排位置，无人机保持未解锁。仍需以实际外框净空为准。
4. **模式准备**：若上一轮保留 Offboard，按界面提示退出并选择 Position；只按当前提示操作 SA，避免连续切换造成模式混淆。
5. **明确起飞**：生成本轮预览，核对路线、速度和活动范围，在起飞确认处明确执行。准备连接、小车就位本身不触发起飞。
6. **联合运行**：无人机起飞、移到车上方，小车执行选定路线，无人机跟随，完成后车停、机返回地面起飞点并缓降。
7. **结束**：等待飞控落地/锁定与小车停车反馈、界面已收尾。需提前结束时点击停止并收尾，复用正常停止/降落流程。

## 轨迹与速度

二维界面与 RViz 显示实测轨迹，车机颜色与标签区分。速度由有效位姿的时间变化估计，不是发送目标速度。位置对照将飞控估计转换到本轮统一参考系后，与 Vicon 机体参考点比较；缺少配准记录或数据失效时显示等待/未知。

历史目录在现场 `vicon_receiver_ws/drone_sim/空地协同回放/`，按任务/日期/结果归档。拖动进度条快进或回退，暂停仅影响回放。历史数据与当前设备状态分开显示。

## 故障解读

| 现象 | 看什么 | 处理方向 |
|---|---|---|
| 无线未就绪 | 哪张网卡、目标 IP/路由、原始连接错误 | 恢复对应设备/热点，不改办公网络 |
| 刚体不可用 | 对象名、遮挡、源帧/数据年龄 | 恢复 Tracker 有效跟踪、检查标记固定 |
| 姿态/坐标不一致 | 刚体版本、外参、实体机头映射 | 校正安装参考，保留世界系来源 |
| 预飞未通过 | PX4 具体报文与融合状态 | 按原始原因处理，不只看总状态 |
| 小车故障 | 原始故障位、轮速反馈、握手状态 | 按控制器故障解释恢复 |
| 收尾未完成 | 落地/锁定、停车反馈、频率恢复分别是否确认 | 保留未完成记录，避免当成任务成功 |

真正运行前保留独立遥控接管与实体隔离；仓库维护、看帮助、回放和离线测试均无需启动电机。
